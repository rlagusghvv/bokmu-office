# 복무ON Office

사회복무요원 복무기관을 위한 내부 업무관리 MVP 프로토타입입니다. 근무상황 신청, 증빙 확인, 출근점검, 결재, 월말 반영을 하나의 업무 화면에서 처리하도록 구성했습니다.

## 열기

브라우저에서 `index.html`을 열면 된다.

```bash
open /Users/kimhyeonho/Documents/Playground/bokmu-office/index.html
```

## 포함된 화면

- 홈 대시보드
- 조직·복무자 관리
- 근무상황 신청
- 결재함
- 출근점검
- 인수인계
- 고충/면담 기록
- 월간 보고서
- 운영설정
- 기관 유형 템플릿
- 개인정보 보호 설정

## 수상용 포지셔닝

담당자의 반복 업무와 사회복무요원의 신청 경험을 개선하는 현장 운영 시스템으로 설명합니다. 핵심 메시지는 `신청-규칙표 확인-출근점검-결재-월말 반영`을 한 흐름으로 묶어 중복 확인과 누락을 줄이는 것입니다.

병무청 사회복무포털 같은 법정 기록 체계는 전국 공통 기록과 감사 대응이 우선이므로 보수적으로 설계될 수밖에 있습니다. 복무ON Office는 기관 내부의 수기 처리 절차를 대체하고, 기관마다 다른 현장 업무흐름은 템플릿과 설정으로 흡수한 뒤 결재 완료 건만 월말 반영 대상으로 분리합니다.

## 고도화 방향

민간 HR툴의 구성원 관리, 셀프서비스, 전자결재, 근태 마감, 리포트 구조를 참고했습니다. 단, 사기업의 급여/채용/평가 기능은 그대로 가져오지 않고 복무기관의 출근점검, 휴가 증빙, 면담, 월말 반영 업무에 맞게 재설계했습니다.

고도화 핵심은 고정 코어와 설정 레이어의 분리입니다. 복무자 기본정보, 근무상황, 결재, 출입신호 확인, 증빙파일, 접속기록, 보존·파기는 공통 코어로 두고, 사회복지시설형, 보건의료형, 교육문화·환경안전형, 행정지원형 템플릿에 따라 결재선, 증빙조건, 업무목록, 보고서 양식을 바꿉니다.
